# Sales Data Cleaning and Analysis (Excel)

## Objective
The objective of this project is to clean and analyze a sales dataset to identify regional performance based on revenue and profit.

## Dataset Description
The dataset contains sales records including client details, revenue, profit, and regional information.

## Data Cleaning Process
The following steps were performed in Excel:
- Removed duplicate records
- Cleaned client names by removing unwanted characters
- Standardized text formatting using TRIM and PROPER functions
- Converted data types (dates, revenue, profit)
- Handled missing values by replacing blanks with "NA"
- Separated Region data using Text-to-Columns
- Resolved calculation errors using IFERROR

## Data Analysis
A Pivot Table and chart were created to analyze revenue and profit by region.

## Key Insights
- New York generated the highest revenue and profit, making it the top-performing region
- California ranked second in both revenue and profit
- Florida showed moderate revenue but lower profitability
- Texas had lower revenue but relatively strong profit, indicating better efficiency
